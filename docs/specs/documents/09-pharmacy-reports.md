# 09 — Pharmacy reports and controlled-substance register

Templates `resources/views/portals/pharmacy/reports/pdf.blade.php` (stock, expiry, valuation,
dispensing) and `controlled_register_pdf.blade.php`. Routes `GET pharmacy/reports/{report}/pdf`
(+ `/csv`), `GET pharmacy/controlled/register?format=pdf|csv`. Pharmacy staff, facility from
`PortalContextService`.

**Basis.** Narcotics / psychotropics register obligation for pharmacies (Single Convention on
Narcotic Drugs 1961 art. 34; Cameroon pharmacy regulation) **[U: MINSANTE register form]**.

## Changes in this pass
- **Verify QR added.** `DocumentVerificationService::issueForFacility()` mints a
  `document_verifications` row with `patient_id = null`, `facility_id` set
  (migration `2026_10_18_130100` makes `patient_id` nullable and adds `facility_id`); the PDF
  bytes are sealed (sha256). Types: `pharmacy_report`, `controlled_register`; the verifier page
  labels them via `doc_ex_sheet.type.*` and shows no holder.
- "Generated by" row (signed-in user).
- Controlled register: pharmacist-in-charge signature and stamp block.
- Served with `Cache-Control: no-store`.

Fields: facility, window/period, generated at/by, tabular rows, valuation in XAF (whole francs).
Print: as 00.
