v2.4.0Feature

FHIR R4 Immunization and Encounter resources now available. Added support for fhir:read scope in Standard tier.

15 May 2026
v2.3.2Fix

Fixed 401 errors on token refresh for mobile clients using PKCE flow. Tokens now refresh correctly without re-authentication.

01 May 2026
v2.3.0Feature

Webhook delivery now includes automatic retry logic — up to 3 retries with exponential backoff (30s, 60s, 120s).

10 Apr 2026
v2.2.1Fix

Resolved pagination cursor issue in GET /api/v2/patients when filtering by facility and date simultaneously.

01 Apr 2026
v2.2.0Feature

Rate limit headers now included in all API responses: X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset.

01 Mar 2026
v2.1.0Breaking

API v1 is now deprecated. All v1 endpoints will be removed on 01 September 2026. Migrate to v2 immediately. See migration guide.
